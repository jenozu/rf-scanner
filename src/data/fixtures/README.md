# SAP-style test fixtures

Synthetic data for the order import tests. Nothing here is real company data.

- `sap-sample.xlsx`: workbook with sheets `Master Inventory`, `Purchase Orders`, `Sales Orders`.
- `po-sample.csv`: the Purchase Orders sheet as CSV.
- `so-sample.csv`: the Sales Orders sheet as CSV.

They are generated by a script outside the repo (column list from the Phase 3 task log). They cover:

- duplicate ItemCode on two lines of one PO (`5000001` lines 1 and 2, `ITEM-100`), and on one SO (`7000001`)
- a closed line (`5000002` line 1, OpenQty 0)
- Excel date serial (`46327`) and an ISO date text
- a quantity written as text with a thousands separator (`"1,000"`)
- bin placeholder `NO-BIN` and SAP system bin `01-SYSTEM-BIN-LOCATION`
- bad rows: invalid quantity (`abc`), missing item code, invalid date text, missing PO number

When the owner's real sample workbook is supplied, replace these files and update the expected values in the tests.
